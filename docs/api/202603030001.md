# Search Members API 擴充說明

## Endpoint
GET /api/v1/members

> 實際後端路由：`GET /tenants/{tenantId}/members`

## Query Parameters
| Name | Type | Required | Description |
|------|------|----------|------------|
| keyword | string | No | 姓名 / Email / 手機號碼 模糊搜尋 |
| memberNo | string | No | 會員編號模糊搜尋 |
| displayName | string | No | 顯示名稱模糊搜尋 |
| phoneNumber | string | No | 手機號碼模糊搜尋 |
| status | short | No | 會員狀態過濾 |
| userId | guid | No | 會員綁定使用者 Id 過濾 |
| page | int | Yes | 頁碼 |
| pageSize | int | Yes | 每頁筆數 |

## Response 範例

```json
{
  "items": [
    {
      "id": "guid",
      "userId": "guid",
      "memberNo": "M0001",
      "displayName": "測試會員",
      "status": 1,
      "createdAt": "2026-03-03T00:00:00Z",
      "updatedAt": "2026-03-03T00:00:00Z",
      "profileRealName": "王小明",
      "profileGender": 1,
      "profilePhoneNumber": "0912345678",
      "profilePhoneVerified": true,
      "profileUpdatedAtUtc": "2026-03-03T00:00:00Z"
    }
  ],
  "totalCount": 100,
  "page": 1,
  "pageSize": 20
}
```

## 查詢行為說明
- `keyword` 會同時對 `members.display_name`、`users.email`、`member_profiles.phone_number` 做 `ILIKE` 模糊比對。
- `phoneNumber` 會額外對 `member_profiles.phone_number` 做獨立模糊比對，可與 `keyword` 疊加。
- 保留原有 `memberNo`、`displayName`、`status`、`userId` 過濾條件與分頁排序行為。
