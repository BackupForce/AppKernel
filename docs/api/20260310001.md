# Current Draw Hot Balls API

## 1. API 名稱
當前期別熱球統計（Current Draw Hot Balls）

## 2. API 路徑
`GET /api/tenants/{tenantId}/me/gaming/draws/current/hot-balls`

## 3. HTTP Method
`GET`

## 4. Request 說明
- Path Parameter
  - `tenantId` (Guid, 必填)：租戶識別。
- Header
  - 需攜帶會員身分驗證（Member Authorization）。
- Query String
  - 無。

## 5. Response JSON 範例
```json
{
  "items": [
    { "number": 5, "betCount": 123 },
    { "number": 12, "betCount": 98 },
    { "number": 3, "betCount": 76 }
  ]
}
```

## 6. 欄位說明
- `items` (array): 熱球統計清單（依下注次數由高到低排序）。
  - `number` (int): 球號。
  - `betCount` (long): 該球號在「當前期別」的有效下注次數。

## 7. 補充說明
- 本 API 提供「當前期別熱球統計」。
- 統計基礎為 `TicketDraw`（單券多期別架構）。
- 僅統計當前 Draw 且屬於有效下注資料（依 SubmissionStatus 與 ParticipationStatus 過濾）。
- 透過資料庫 SQL aggregation（`GROUP BY`）直接計算，避免將大量資料回拋到應用層記憶體統計。
