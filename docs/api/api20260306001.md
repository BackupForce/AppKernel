# API 串接文件（前端）- Member Tag / TicketClaimEvent Tag 條件

> 文件版本：2026-03-06  
> 檔名：`api20260306001.md`  
> 適用範圍：本次新增與異動 API（Member Tag CQRS + TicketClaimEvent AllowedTagIds）

---

## 1) 基本資訊

- Base Path（Admin）：`/tenants/{tenantId}/admin`
- 認證：沿用既有 TenantUser 授權機制（Bearer Token）
- Content-Type：`application/json`
- 時間欄位：UTC（ISO-8601）

---

## 2) 新增 API：Member Tag 管理

## 2.1 建立 Tag

- **Method / Path**：`POST /tenants/{tenantId}/admin/member-tags`
- **Request Body**

```json
{
  "tagCode": "vip",
  "displayName": "VIP 會員"
}
```

- **Response 200**：`Guid`（新建 tagId）

- **錯誤碼（常見）**
  - `Gaming.MemberTagTenantMismatch`
  - `Gaming.MemberTagCodeInvalid`
  - `Gaming.MemberTagDisplayNameInvalid`
  - `Gaming.MemberTagCodeDuplicated`

---

## 2.2 更新 Tag 名稱

- **Method / Path**：`PUT /tenants/{tenantId}/admin/member-tags/{tagId}`
- **Request Body**

```json
{
  "displayName": "高價值會員"
}
```

- **Response 200**：無 body

- **錯誤碼（常見）**
  - `Gaming.MemberTagTenantMismatch`
  - `Gaming.MemberTagDisplayNameInvalid`
  - `Gaming.MemberTagNotFound`

---

## 2.3 停用 Tag

- **Method / Path**：`POST /tenants/{tenantId}/admin/member-tags/{tagId}/deactivate`
- **Request Body**：無
- **Response 200**：無 body

- **錯誤碼（常見）**
  - `Gaming.MemberTagTenantMismatch`
  - `Gaming.MemberTagNotFound`

---

## 2.4 查詢 Tag 列表（分頁）

- **Method / Path**：`GET /tenants/{tenantId}/admin/member-tags`
- **Query Parameters**
  - `keyword?: string`
  - `isActive?: boolean`
  - `page: number`（>=1）
  - `pageSize: number`（1~200）

- **Response 200**：`PagedResult<MemberTagDto>`

```json
{
  "items": [
    {
      "id": "8c6b5d0c-7b8b-4696-88a9-5f81d45e1c8f",
      "tagCode": "vip",
      "displayName": "VIP 會員",
      "isActive": true,
      "createdAtUtc": "2026-03-06T10:00:00Z",
      "updatedAtUtc": "2026-03-06T10:00:00Z"
    }
  ],
  "page": 1,
  "pageSize": 20,
  "totalCount": 1,
  "totalPages": 1
}
```

- **前端注意**：`page`、`pageSize` 不合法時會回 `400 BadRequest`（文字訊息）。

## 3) 新增 API：會員 Tag 綁定

## 3.1 取得會員已綁定 Tags

- **Method / Path**：`GET /tenants/{tenantId}/admin/members/{memberId}/tags`
- **Response 200**：`MemberTagDto[]`

```json
[
  {
    "id": "8c6b5d0c-7b8b-4696-88a9-5f81d45e1c8f",
    "tagCode": "vip",
    "displayName": "VIP 會員",
    "isActive": true,
    "createdAtUtc": "2026-03-06T10:00:00Z",
    "updatedAtUtc": "2026-03-06T10:00:00Z"
  }
]
```

- **錯誤碼（常見）**
  - `Gaming.MemberTagTenantMismatch`
  - `Gaming.MemberNotFound`

---

## 3.2 覆寫會員 Tag 綁定（Replace）

- **Method / Path**：`PUT /tenants/{tenantId}/admin/members/{memberId}/tags`
- **語意**：全量覆寫（不是增量）
- **Request Body**

```json
{
  "tagIds": [
    "8c6b5d0c-7b8b-4696-88a9-5f81d45e1c8f",
    "d4f9b26e-b40d-4f24-9f4b-f9d6d09e8db1"
  ]
}
```

- **Response 200**：無 body

- **錯誤碼（常見）**
  - `Gaming.MemberTagTenantMismatch`
  - `Gaming.MemberNotFound`
  - `Gaming.MemberTagNotFound`
  - `Gaming.MemberTagInactive`

- **前端注意**
  - 若要清空會員所有 tag，傳 `tagIds: []`。
  - 建議前端先做 `Set` 去重複，雖後端也會去重。

## 4) 異動 API：TicketClaimEvent Create/Update

本次在既有 API 增加 `allowedTagIds` 欄位（可空/可省略）。

## 4.1 建立活動

- **Method / Path**：`POST /tenants/{tenantId}/admin/ticket-claim-events`
- **新增欄位**：`allowedTagIds?: Guid[]`

```json
{
  "name": "春季活動",
  "startsAtUtc": "2026-03-07T00:00:00Z",
  "endsAtUtc": "2026-03-31T00:00:00Z",
  "totalQuota": 1000,
  "perMemberQuota": 1,
  "scopeType": "SingleDraw",
  "scopeId": "72eeb219-640a-44fd-9f89-3f2576a0268b",
  "ticketTemplateId": "a8836c2c-3f42-47b7-8f69-5a7424d7a594",
  "allowedTagIds": [
    "8c6b5d0c-7b8b-4696-88a9-5f81d45e1c8f"
  ]
}
```

- **Response 200**：`Guid`（eventId）

---

## 4.2 更新活動

- **Method / Path**：`PUT /tenants/{tenantId}/admin/ticket-claim-events/{id}`
- **新增欄位**：`allowedTagIds?: Guid[]`

```json
{
  "name": "春季活動-更新",
  "startsAtUtc": "2026-03-07T00:00:00Z",
  "endsAtUtc": "2026-04-05T00:00:00Z",
  "totalQuota": 1200,
  "perMemberQuota": 1,
  "scopeType": "SingleDraw",
  "scopeId": "72eeb219-640a-44fd-9f89-3f2576a0268b",
  "ticketTemplateId": "a8836c2c-3f42-47b7-8f69-5a7424d7a594",
  "allowedTagIds": [
    "8c6b5d0c-7b8b-4696-88a9-5f81d45e1c8f",
    "d4f9b26e-b40d-4f24-9f4b-f9d6d09e8db1"
  ]
}
```

- **Response 200**：無 body

- **錯誤碼（Create/Update 都可能）**
  - `Gaming.MemberTagNotFound`
  - `Gaming.MemberTagInactive`

- **前端注意**
  - `allowedTagIds` 為空或未傳 => 活動不限制 tag。
  - 有值 => claim 時需命中至少一個 active tag。

---

## 5) 前端行為影響（既有 API 無改路徑）

## 5.1 會員可見活動查詢

- API：`GET /frontend/.../ticket-claim-events/active`（既有）
- 行為：活動若有 tag 規則，會員需命中任一 active tag 才會出現在清單。

## 5.2 領券 Claim

- API：`POST /frontend/.../ticket-claim-events/{eventId}/claim`（既有）
- 行為：claim 時再次做 tag 資格檢查（即時一致）。
- 可能新增錯誤：`Gaming.TicketClaimEventMemberTagNotEligible`

---

## 6) 前端建議串接流程

1. 後台活動編輯頁：先呼叫 `GET /admin/member-tags` 取得可選 tags。
2. 建立/更新活動時帶入 `allowedTagIds`。
3. 會員詳情頁：
   - `GET /admin/members/{memberId}/tags` 顯示當前綁定
   - `PUT /admin/members/{memberId}/tags` 做全量覆寫
4. 前台活動列表與 claim：直接沿用既有 API，顯示/資格會自動反映 tag 變更。
