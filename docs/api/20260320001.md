# Tickets API 更新說明（2026-03-20）

## 1. 變更摘要
- 擴充後台 `/admin/gaming/tickets`（實際完整路徑含 tenant 前綴）回傳欄位，新增 `displayName`。
- 新增後台會員視角查詢 API：`GET /api/tenants/{tenantId}/admin/members/{memberId}/tickets`。
- 會員顯示名稱來源與 `/api/tenants/{tenantId}/admin/gaming/draws/{drawId}/tickets` 一致，皆取自 `members.display_name`。

## 2. API 1：/gaming/tickets 新增 displayName 欄位

### 路由
`GET /api/tenants/{tenantId}/admin/gaming/tickets`

### Method
`GET`

### 權限
`TICKETS:READ`

### Query Parameters / Request
沿用既有查詢參數：
- `drawId` (Guid, optional)
- `status` (string, optional)
- `memberId` (Guid, optional)
- `memberNo` (string, optional)
- `issuedFromUtc` (datetime, optional)
- `issuedToUtc` (datetime, optional)
- `submittedFromUtc` (datetime, optional)
- `submittedToUtc` (datetime, optional)
- `createdFromUtc` (datetime, optional)
- `createdToUtc` (datetime, optional)
- `page` (int, optional, default `1`)
- `pageSize` (int, optional, default `20`, max `200`)

### Response 欄位說明
回傳型別為分頁物件：
- `items[].ticketId`：票券識別碼。
- `items[].memberId`：會員識別碼。
- `items[].memberNo`：會員編號。
- `items[].displayName`：會員顯示名稱，來源為 `members.display_name`。
- `items[].gameCode`：遊戲代碼。
- `items[].drawId`：期數識別碼。
- `items[].drawCode`：期數代碼。
- `items[].submissionStatus`：票券送單狀態。
- `items[].issuedAtUtc`：發券時間（UTC）。
- `items[].submittedAtUtc`：送單時間（UTC）。
- `items[].cancelledAtUtc`：取消時間（UTC）。
- `items[].issuedByType`：發券來源類型。
- `items[].issuedByUserId`：發券操作人員。
- `items[].submittedByUserId`：送單操作人員。
- `items[].lineCount`：注數數量。
- `items[].createdAt`：建立時間。

## 3. API 2：/admin/members/{memberId}/tickets

### 路由
`GET /api/tenants/{tenantId}/admin/members/{memberId}/tickets`

### Method
`GET`

### 權限
`TICKETS:READ`

### Path 參數
- `tenantId` (Guid, required)：租戶識別碼。
- `memberId` (Guid, required)：欲查詢票券的會員識別碼。

### Query Parameters
- `page` (int, optional, default `1`)
- `pageSize` (int, optional, default `20`, max `200`)

### Response 欄位說明
回傳型別為分頁物件，欄位語意對齊 Draw Tickets API：
- `items[].ticketId`：票券識別碼。
- `items[].memberId`：會員識別碼。
- `items[].memberNo`：會員編號。
- `items[].displayName`：會員顯示名稱。
- `items[].gameCode`：遊戲代碼。
- `items[].submissionStatus`：票券送單狀態。
- `items[].issuedAtUtc`：發券時間（UTC）。
- `items[].submittedAtUtc`：送單時間（UTC，可為 null）。
- `items[].participationStatus`：票券參與指定 Draw 的狀態；若票券尚未綁定 draw，回傳 `Pending`。
- `items[].lines[]`：注數清單。
  - `lineIndex`：注數索引。
  - `playTypeCode`：玩法代碼。
  - `numbers`：原始投注號碼字串。

## 4. 狀態欄位補充說明
- `submissionStatus`：沿用既有 `TicketSubmissionStatus` 定義，常見值為 `NotSubmitted`、`Submitted`、`Cancelled`。
- `participationStatus`：沿用既有 `TicketDrawParticipationStatus` 定義；會員票券查詢中，若尚未綁定任何 draw，會以 `Pending` 回傳。
- `issuedByType`：沿用既有 `IssuedByType` 定義。
