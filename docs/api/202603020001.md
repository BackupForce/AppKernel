# 202603020001 - Admin 中獎兌獎（Redeem Winning）API

## 1) 背景與目的
提供 Admin 後台對中獎資料的管理能力，包含：
- 依期數查詢中獎/兌獎清單
- 查詢單筆中獎明細
- 執行兌獎（避免重複兌獎）

此版本為後台專用，不可與會員端兌獎流程混用。

## 2) Auth 說明
- 使用 Tenant Admin JWT Bearer Token。
- Header：`Authorization: Bearer <token>`
- 路由需帶 `tenantId`。

## 3) 權限需求
至少需包含下列 permission code：
- `admin.gaming.winning-numbers.read`
- `admin.gaming.winnings.read`
- `admin.gaming.winnings.redeem`

對應 API：
- 查詢清單/明細：`admin.gaming.winnings.read`
- 執行兌獎：`admin.gaming.winnings.redeem`

## 4) API 清單

## 4.1 查詢某期中獎清單
**Method**: `GET`  
**URL**: `/tenants/{tenantId}/admin/gaming/draws/{drawId}/winnings`

### Path Params
```ts
interface GetAdminWinningsPathParams {
  tenantId: string;
  drawId: string;
}
```

### Query Params
```ts
interface GetAdminWinningsQuery {
  q?: string;
  redeemed?: boolean;
  current?: number; // default: 1
  pageSize?: number; // default: 50, max: 200
}
```

### Response
```ts
interface PagedResult<T> {
  items: T[];
  totalCount: number;
  page: number;
  pageSize: number;
}

interface AdminWinningListItemDto {
  winningId: string;
  ticketId: string;
  drawId: string;
  drawDateUtc: string;
  payoutAmount: number;
  status: number;
  redeemedAtUtc: string | null;
  redeemedByUserId: string | null;
  redeemedByUserName: string | null;
}
```

### 錯誤碼
- `400`: current/pageSize 不合法
- `401`: 未登入
- `403`: 無 `admin.gaming.winnings.read`

## 4.2 查詢單筆中獎明細
**Method**: `GET`  
**URL**: `/tenants/{tenantId}/admin/gaming/winnings/{winningId}`

### Path Params
```ts
interface GetAdminWinningDetailPathParams {
  tenantId: string;
  winningId: string;
}
```

### Response
```ts
interface AdminWinningDetailDto {
  winningId: string;
  tenantId: string;
  ticketId: string;
  drawId: string;
  drawDateUtc: string;
  drawCode: string;
  payoutAmount: number;
  prizeTier: string;
  status: number;
  settledAtUtc: string;
  redeemedAtUtc: string | null;
  redeemedByUserId: string | null;
  redeemedByUserName: string | null;
}
```

### 錯誤碼
- `401`: 未登入
- `403`: 無 `admin.gaming.winnings.read`
- `404`: 找不到 winningId

## 4.3 執行兌獎
**Method**: `POST`  
**URL**: `/tenants/{tenantId}/admin/gaming/winnings/{winningId}/redeem`

### Path Params
```ts
interface RedeemWinningPathParams {
  tenantId: string;
  winningId: string;
}
```

### Body
無。

### Response
回傳更新後 `AdminWinningDetailDto`。

### 錯誤碼
- `400`: winningId 不合法
- `401`: 未登入
- `403`: 無 `admin.gaming.winnings.redeem`
- `404`: 找不到 winningId
- `409`: 已兌獎或狀態不可兌獎

## 5) Axios 呼叫範例（嚴格 typing）
```ts
import axios, { AxiosInstance } from "axios";

export interface AdminWinningDetailDto {
  winningId: string;
  tenantId: string;
  ticketId: string;
  drawId: string;
  drawDateUtc: string;
  drawCode: string;
  payoutAmount: number;
  prizeTier: string;
  status: number;
  settledAtUtc: string;
  redeemedAtUtc: string | null;
  redeemedByUserId: string | null;
  redeemedByUserName: string | null;
}

export interface AdminWinningListItemDto {
  winningId: string;
  ticketId: string;
  drawId: string;
  drawDateUtc: string;
  payoutAmount: number;
  status: number;
  redeemedAtUtc: string | null;
  redeemedByUserId: string | null;
  redeemedByUserName: string | null;
}

export interface PagedResult<T> {
  items: T[];
  totalCount: number;
  page: number;
  pageSize: number;
}

export async function getAdminWinningsByDraw(
  client: AxiosInstance,
  tenantId: string,
  drawId: string,
  query: { q?: string; redeemed?: boolean; current?: number; pageSize?: number }
): Promise<PagedResult<AdminWinningListItemDto>> {
  const response = await client.get<PagedResult<AdminWinningListItemDto>>(
    `/tenants/${tenantId}/admin/gaming/draws/${drawId}/winnings`,
    { params: query }
  );

  return response.data;
}

export async function getAdminWinningDetail(
  client: AxiosInstance,
  tenantId: string,
  winningId: string
): Promise<AdminWinningDetailDto> {
  const response = await client.get<AdminWinningDetailDto>(
    `/tenants/${tenantId}/admin/gaming/winnings/${winningId}`
  );

  return response.data;
}

export async function redeemWinning(
  client: AxiosInstance,
  tenantId: string,
  winningId: string
): Promise<AdminWinningDetailDto> {
  const response = await client.post<AdminWinningDetailDto>(
    `/tenants/${tenantId}/admin/gaming/winnings/${winningId}/redeem`
  );

  return response.data;
}
```

## 6) 前端注意事項
- 兌獎按鈕點擊後要立即進入 loading + disabled，避免重複送出。
- 若收到 `409`，前端應 refresh 該筆明細並提示「該筆已兌獎或狀態已變更」。
- 清單頁可先 optimistic update（標示已兌獎），但建議以 API 回傳 detail 為準。
- 多管理員並發下，僅第一筆成功，後續呼叫會收到 `409`。
