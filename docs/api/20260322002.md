# 20260322002 - Ticket Claim Event Claims API 欄位擴充

## 1. API 用途
- API：`GET /api/v1/tenants/{tenantId}/gaming/ticket-claim-events/{id}/claims`
- 用途：查詢指定 Ticket Claim Event 的領取紀錄清單，回傳分頁資料，供後台顯示每筆領取紀錄的會員與票券資訊。

## 2. 查詢條件說明
維持既有查詢條件與行為不變：
- `tenantId`（path, Guid, required）：租戶識別碼。
- `id`（path, Guid, required）：Ticket Claim Event 識別碼。
- `memberId`（query, Guid, optional）：指定會員查詢。
- `claimedFromUtc`（query, datetime, optional）：領取時間起始（UTC）。
- `claimedToUtc`（query, datetime, optional）：領取時間結束（UTC）。
- `page`（query, int, optional, default `1`）：頁碼。
- `pageSize`（query, int, optional, default `20`, max `200`）：每頁筆數。

補充：
- 排序維持 `claimed_at_utc DESC`。
- 分頁維持既有 `Page` / `PageSize` / `Offset` / `totalCount` 邏輯。

## 3. 回傳欄位說明
回傳型別為 `PagedResult<TicketClaimRecordDto>`：

- `items[].id`：領取紀錄識別碼。
- `items[].memberId`：會員識別碼。
- `items[].memberNo`：會員編號。
- `items[].displayName`：會員顯示名稱。
- `items[].quantity`：本次領取數量。
- `items[].claimedAtUtc`：領取時間（UTC）。
- `items[].issuedTicketIds`：本次領取所發出的票券識別碼清單。
- `totalCount`：符合條件的總筆數。
- `page`：目前頁碼。
- `pageSize`：每頁筆數。

## 4. 本次新增欄位
本次僅擴充 response 欄位，不變更既有 route、查詢條件與分頁格式：
- `memberNo`
- `displayName`

## 6. 前端型別調整建議
若前端已有 `TicketClaimRecordDto` / `TicketClaimRecord` 型別，請新增以下欄位：

```ts
export interface TicketClaimRecordDto {
  id: string;
  memberId: string;
  memberNo: string;
  displayName: string;
  quantity: number;
  claimedAtUtc: string;
  issuedTicketIds: string[];
}
```

建議調整項目：
1. 列表欄位新增「會員編號」與「會員名稱」。
2. 若目前 UI 僅顯示 `memberId`，可優先改顯示 `memberNo + displayName`。
3. 既有 `issuedTicketIds` 仍維持陣列格式，前端不需修改反序列化邏輯。
