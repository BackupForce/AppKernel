# API: Get Draw Winning Numbers By Uid

## Endpoint
GET /public/draws/{uid}/winning-numbers

## Description
透過 uid 取得指定 Draw 的開獎號碼。

## Path Parameters

| Name | Type | Required | Description |
|------|------|----------|------------|
| uid  | string | Yes | Draw unique identifier |

## Success Response (200)

{
  "drawId": "uuid",
  "uid": "20260225-001",
  "drawDateUtc": "2026-02-25T12:00:00Z",
  "winningNumbers": [5, 12, 23, 37, 44]
}

## Not Found (404)

{
  "type": "NotFound",
  "code": "Draw.NotFound",
  "message": "Draw with uid 'xxx' was not found."
}
